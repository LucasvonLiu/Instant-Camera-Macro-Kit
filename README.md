# 拍立得微距对焦支架与 M37 滤镜转接套件 (Instant Camera Macro Close-up Kit)

[![Format: 3DM / STL](https://img.shields.io/badge/CAD-Rhino%203DM%20%7C%20STL-green.svg)](#文件架构说明)

本项目为专为**拍立得 / 即时成像相机（Polaroid / Instax 等系统）**设计的 3D 打印微距对焦测距支架与 **M37 (37mm) 滤镜转接环** 开源套件。包含完整的 CAD 建模工程源文件（Rhinoceros `.3dm`）及可直接 3D 打印的 STL 文件。

---

## 📷 设计背景与工作原理 (Design & Principles)

### 1. 为什么需要物理对焦支架？
大多数拍立得与即时成像相机为**定焦**或**最近对焦距离较远**（通常在 0.6m ~ 1m 以上），且采用旁轴光学取景器：
- **失焦模糊**：无法直接贴近拍摄微距特写（如花草、手办、微小静物等）。
- **严重视差 (Parallax Error)**：在 10~20cm 的超近距离下，取景窗口所见画面与镜头实际光轴存在巨大偏差，盲拍极易出现严重构图偏斜。

### 2. 解决方案：近摄镜 + 物距标定框
通过加装标准 **37mm (M37) 螺口的近摄镜片（Diopter: +4 / +8 / +10）**，配合精密设计的物理伸出支架（Framing / Standoff Arms）：
- **物理精准对焦**：支架末端即为光学成像的最佳焦平面，无需对焦屏，直接将支架前端对准被摄物体表面即可获得清晰合焦。
- **物理界定画幅**：支架末端的定位框直接勾勒出感光画面的实际拍摄范围，彻底消除旁轴视差，所见即所拍。

## 🖨️ 3D 打印与制作指南 (3D Printing Guidelines)

| 打印参数 | 推荐设置 | 说明 |
| :--- | :--- | :--- |
| **推荐材质** | **PLA+** / **PLA-CF** / **PETG** | 支架臂要求刚性好、抗弯折，PLA-CF 或优质 PLA+ 是极佳选择 |
| **外观颜色** | **哑光黑 (Matte Black)** | 减少转接环反光，建议靠近镜头部分采用消光黑 |
| **层高 (Layer Height)** | `0.16 mm` - `0.20 mm` | 保证伸展臂表面光滑无毛刺，螺纹配合顺畅 |
| **壁厚层数 (Wall Loops)** | `≥ 4 层` | 增加伸出支架的抗压刚度，防止使用中受力弯曲导致焦距偏移 |
| **填充率 (Infill)** | `25% ~ 40%` (推荐 Gyroid 陀螺仪填充) | 保证强度与重量平衡 |
| **支撑设置** | 根据打印摆放方向开启树状支撑 (Tree Support) | 建议将卡口/螺纹基底朝下平放打印 |

## 🔩 硬件配件与组装 (Hardware Assembly)

1. **近摄镜片选型**：市售通用的 **37mm 螺纹近摄镜组 (Close-up Filter Kit: +4, +8, +10)**，价格实惠且成像光学稳定。
2. **装配方式**：将 37mm 近摄镜旋入转接环基座，再将对应物距的支架安装至相机镜头前端。
3. **拍摄技巧**：
   - 将支架前端轻轻靠近目标物体表面（或置于画框中心）。
   - 由于微距拍摄景深极浅，建议在光线充足的室外或配合补光灯使用，以促使相机自动选择较小光圈提升景深清晰范围。
